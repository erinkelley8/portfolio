# Data card: Met Open Access

| Field | Value |
|---|---|
| Publisher | The Metropolitan Museum of Art |
| Source | https://github.com/metmuseum/openaccess (`MetObjects.csv`; stored in Git LFS) |
| Download URL used | `https://media.githubusercontent.com/media/metmuseum/openaccess/master/MetObjects.csv` |
| Licence | Creative Commons Zero (CC0 1.0) |
| Content | Object-level metadata for the Met collection (~470k records at last documentation). Images are not included. |
| Method | One-time bulk snapshot, manually triggered |
| Snapshot date / checksum | See `manifest.json` (generated by the download script) |
| Update behaviour | Source is updated by the Met; this repo does not auto-refresh |

## Intended use
Descriptive analysis of collection composition, open-access coverage, and metadata completeness.

## Known limits
- Data is provided "as is" by the source.
- Many fields are free text and sparsely populated; date fields are not always numeric years.
- Results describe the collection as of the snapshot date only.

## Privacy check
Records describe artworks and (historical) makers. No personal data about living private individuals is expected. If any is found, document it here and stop.

## Modifications
Transformations are in `sql/`. Any published result derived from this data must make clear it has been modified.
